# Gravio – Link-Seite

Öffnet Aufträge aus Gravio Dispo auf dem Android-Handy in der Gravio-App.
- `freischalten/`: trägt einen Freischaltcode in GravioLOG ein (`gravio://freischalten`).
- `code/`: Freischaltcode-Anfrage aus der App – öffnet GravioLOG Codes und trägt Geräte-Nummer und Fahrer ein
  (`graviocode://anfrage?d=…&n=…`). Enthält keinen Schlüssel.

Die Auftragsdaten stehen nur im Link hinter dem `#` und werden nie an diesen Server übertragen.
